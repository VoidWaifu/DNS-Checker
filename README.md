# DNS Checker 🌐

**Проверка всех DNS-записей любого домена.**

[Открыть приложение](https://voidwaifu.github.io/DNS-Checker/)

## Что это?

Браузерный инструмент для проверки **всех DNS-записей** домена. Вводите домен или ссылку — получаете полную информацию о его DNS-конфигурации.

## Какие записи проверяются?

- **A** — IPv4 адрес
- **AAAA** — IPv6 адрес
- **MX** — почтовые серверы
- **TXT** — текстовые записи (SPF, DKIM и др.)
- **CNAME** — канонические имена
- **NS** — DNS-серверы
- **SOA** — информация о зоне
- **SRV** — сервисные записи
- **CAA** — сертификаты
- **DS / DNSKEY** — DNSSEC
- **NAPTR** — преобразование адресов
- **PTR** — обратные записи

## Особенности

- 🔍 **14 типов записей** — полная проверка
- ⚡ **Быстро** — все запросы через Google DNS
- 🌍 **Два языка** — русский и английский
- 📱 **Адаптивный дизайн** — работает на любых устройствах
- 🎯 **Автоматическое извлечение домена** — вставляйте ссылку целиком

## Как использовать?

1. Введите домен или ссылку (например, `example.com` или `https://example.com`)
2. Нажмите «Проверить DNS»
3. Просматривайте результаты по типам записей

## Технологии

- **Google DNS API** — источник DNS-данных
- **Чистый HTML + CSS + JavaScript**
- **Без серверов** — работает прямо в браузере
